DIGITAL INTELLIGENCE WEBSITE

Files:
1. index.html     -> Home page
2. services.html  -> Services page
3. contact.html   -> Contact page
4. style.css      -> Complete design/style for all pages
5. script.js      -> Mobile menu, scroll animation, counters, FAQ and contact form interaction

HOW TO RUN:
- Put all 5 files in the SAME folder.
- Open index.html in VS Code.
- If Live Server is installed, right-click index.html -> Open with Live Server.
- Use the navigation to move between the 3 pages.

IMPORTANT:
- The contact form is currently a front-end demo. It does NOT send email by itself.
- Replace the sample email and Instagram link in the HTML with your real business details.
